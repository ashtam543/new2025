12 factor app
Codebase: Each microservice should have its own repository.
Dependencies: Explicitly declare dependencies (e.g., in package.json for Node.js or requirements.txt for Python).
Config: Use environment variables to store configurations, avoiding hardcoding.
Backing Services: Treat external services (e.g., databases, queues) as attached resources.
Build, Release, Run: Separate these stages for consistent deployments.
Processes: Build stateless services to simplify scaling.
Port Binding: Ensure each service exposes itself via ports.
Concurrency: Design services to scale horizontally.
Disposability: Services should start up and shut down gracefully.
Dev/Prod Parity: Minimize differences between development and production environments.
Logs: Treat logs as event streams and manage them centrally.
Admin Processes: Run one-off admin tasks as separate processes.
